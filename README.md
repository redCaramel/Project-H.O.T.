# How to Play?
Sorry, this project was designed to use Arduino serial communication for I/O. 

Due to the loss of the Arduino source code, the project is currently unplayable.

Instead, we have provided the build files and instructions for connecting to the VR headset below:

1. Download SteamVR and iVRy driver. ( download iVRy driver in your mobile device and desktop both.)
2. Connect desktop with mobile device.
3. Run iVRy App in mobile device.
4. Check connection, and Run Game.
